The squirrels in my garden buried my car keys — and every spring they dig up three of them and leave one on the doormat, like rent. Built for make.fun's "Make the Judge Laugh in One Line" bounty.

## Run it

```sh
node main.ts
```

This writes the line (130 characters, one line, no trailing newline) to `/output/entry.txt`. The program checks its own output first: the line must be 1–200 characters and not whitespace-only, and the file on disk must match the line byte for byte.
